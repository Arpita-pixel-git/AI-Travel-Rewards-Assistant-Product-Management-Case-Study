# 09 — Metrics & KPIs

## North Star Metric

### Successful Reward Optimization

Percentage of active users who complete a redemption using a product recommendation.

This metric connects product engagement with the core user value proposition.

## Acquisition Metrics

- New users
- Onboarding completion
- Card/reward data added
- Travel goals created

## Engagement Metrics

- AI recommendations viewed
- Recommendation interactions
- Repeat searches
- Travel goals created per user

## Conversion Metrics

- Recommendation → redemption conversion
- Recommendation acceptance rate
- Redemption completion rate

## Retention Metrics

- 30-day retention
- Repeat travel planning
- Repeat recommendation usage

## AI Quality Metrics

- Recommendation accuracy
- Groundedness
- Hallucination rate
- User-reported recommendation quality

## Guardrail Metrics

- Incorrect recommendation rate
- Outdated-data incidents
- User complaints
- Failed redemption attempts

## Key Product Question

The goal is not simply to increase the number of recommendations viewed.

The goal is to determine whether recommendations help users make **better reward decisions**.
