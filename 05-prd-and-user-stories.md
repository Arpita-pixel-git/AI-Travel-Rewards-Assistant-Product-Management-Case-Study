# 05 — PRD & User Stories

## Product Goal

Enable users to create a travel goal and receive personalized reward redemption recommendations.

## MVP Scope

### 1. User Onboarding

Users can provide:

- Reward cards
- Reward balances
- Travel preferences
- Preferred destinations

### 2. Travel Goal Creation

Users can define:

- Destination
- Travel dates
- Cabin preference
- Number of travelers
- Flight/hotel preference

### 3. Reward Analysis

The system evaluates:

- Available points
- Transfer options
- Redemption value
- User preferences
- Relevant constraints

### 4. Recommendation

The system presents ranked redemption options with an explanation.

## User Stories

### Travel Goal

> As a user, I want to create a travel goal so that I can understand how my rewards can help me achieve it.

### Recommendation

> As a user, I want personalized redemption recommendations so that I don't have to manually compare multiple options.

### Explainability

> As a user, I want to understand why an option is recommended so that I can trust the decision.

### Comparison

> As a user, I want to compare redemption options so that I can choose the one that provides the best value.

## MVP Non-Goals

- Full travel booking
- Complete financial management
- Automated transactions
- Complex concierge services
