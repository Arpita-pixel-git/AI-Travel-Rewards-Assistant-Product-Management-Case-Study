# 10 — Roadmap & GTM

## Phase 1 — MVP

### Objective
Prove that personalized recommendations can help users make better redemption decisions.

### Features

- User onboarding
- Reward balance input
- Travel goal creation
- Basic redemption recommendations
- Recommendation explanation

## Phase 2 — Personalization

### Objective
Improve recommendation quality using deeper user and rewards data.

### Features

- Card portfolio integration
- Real-time rewards data
- Personalized recommendations
- Partner-transfer optimization
- Redemption alerts

## Phase 3 — AI Travel Assistant

### Objective
Move from reactive recommendations to proactive travel planning.

### Features

- Proactive travel opportunities
- Predictive reward opportunities
- Personalized travel planning
- AI-powered travel concierge

## GTM Strategy

### Initial Target

Travel-reward enthusiasts and high-intent credit-card users who actively seek ways to maximize their points.

### Acquisition Channels

- Educational content
- Social media
- Travel-reward communities
- SEO around reward optimization
- Referral programs
- Partnerships with travel and credit-card ecosystems

### Activation Moment

The key activation moment is when a user sees a recommendation that is clearly more valuable or easier to execute than what they would have discovered manually.

## Product-Led Growth Loop

**Discover value → Create goal → Receive recommendation → Redeem → Experience value → Return for next trip**
