# 06 — UX Flow

## Core User Journey

The core experience follows:

**Onboarding → Rewards → Travel Goal → AI Analysis → Recommendations → Decision**

## Step 1 — Onboarding

User provides reward-card information and available points.

↓

## Step 2 — Rewards Overview

User sees a unified view of their reward portfolio.

↓

## Step 3 — Create Travel Goal

User selects destination, dates, travel preferences, and desired experience.

↓

## Step 4 — AI Analysis

The system evaluates available rewards and relevant redemption paths.

↓

## Step 5 — Recommendations

The user receives ranked options based on:

- Value
- Availability
- User preference
- Points required
- Transfer requirements

↓

## Step 6 — Explain Recommendation

AI explains:

- Why this option is recommended
- How many points are required
- Estimated value
- Alternative options
- Important considerations

↓

## Step 7 — User Decision

The user selects the preferred redemption path.

## UX Principle

The experience should reduce cognitive load by transforming a complex research process into a simple decision journey.
